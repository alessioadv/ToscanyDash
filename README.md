# 🏡 Tuscany Dash
### Corri, costruisci e conquista la Toscana! 🇮🇹

Un'avventura arcade tra le colline toscane, dove ogni livello è un nuovo progetto e ogni moneta ti avvicina al tuo sogno: diventare un vero imprenditore toscano.

Inizia la tua avventura a Firenze, ristruttura un rustico, sviluppa il tuo vivaio e costruisci la tua fattoria. Raccogli risorse, schiva gli ostacoli, potenzia il tuo personaggio e trasforma una piccola impresa in un impero!

**🔨 Un muratore. 🏡 Una Toscana da conquistare. 💰 Un impero da costruire.**

---

## 🌄 Il gioco

**Tuscany Dash** è un gioco arcade in cui riflessi, progressione e gestione delle risorse si incontrano in un viaggio attraverso la Toscana.

Durante le partite dovrai muoverti rapidamente, raccogliere oggetti, evitare i pericoli e utilizzare i tuoi strumenti per avanzare. Completando i livelli guadagnerai denaro e marmo, risorse fondamentali per sviluppare le tue attività.

Ma la corsa è solo l'inizio: tra una partita e l'altra potrai visitare il tuo hub, acquistare potenziamenti, controllare l'inventario e investire nei tuoi progetti.

### ✨ Caratteristiche principali

- 🏛️ **4 livelli progressivi**, ambientati in scenari ispirati alla Toscana.
- 👷 **Personaggi selezionabili:** scegli tra muratore e muratrice.
- 🪙 **Raccolta di risorse:** accumula marmo e denaro per finanziare la tua crescita.
- 🛒 **Mercato e potenziamenti:** investi in martelli, caschi, velocità e pale professionali.
- 🏡 **Ristrutturazione immobiliare:** trasforma un rustico in una proprietà di lusso.
- 🌱 **Gestione del vivaio:** sviluppa la tua collezione di piante.
- 🚜 **Sviluppo della fattoria:** raccogli e gestisci una varietà di animali.
- 💾 **Salvataggio automatico:** conserva i tuoi progressi direttamente nel browser.
- 🎵 **Audio integrato:** effetti sonori e musica generati tramite Web Audio API.
- 📱 **Interfaccia responsive:** gioca sia su desktop sia su dispositivi mobili.
- ⏸️ **Menu di pausa e inventario:** gestisci le tue risorse senza perdere di vista i tuoi obiettivi.

## 💾 Salvataggi e progressi

Tuscany Dash utilizza il sistema `localStorage` del browser per conservare i dati della partita.

Il salvataggio comprende:

- 💰 Denaro accumulato
- 💎 Marmo raccolto
- 👷 Personaggio selezionato
- 🏆 Livelli completati
- 🛒 Potenziamenti acquistati
- 🏡 Progressi nella ristrutturazione
- 🌱 Collezione del vivaio
- 🐄 Collezione della fattoria

Il gioco salva automaticamente i progressi e mette a disposizione un comando per salvare manualmente dal menu di pausa.

> **Attenzione:** i dati sono memorizzati localmente nel browser. Cancellando i dati del sito o utilizzando un altro browser o dispositivo, potresti perdere o non ritrovare i progressi. Al momento il sistema non prevede la sincronizzazione online dei salvataggi.

## 🚀 Come avviare il gioco

Tuscany Dash è realizzato come una pagina web autonoma, con HTML, CSS e JavaScript.

Non richiede l'installazione di framework o pacchetti aggiuntivi per essere eseguito nella sua configurazione attuale.

### Metodo 1 — Avvio locale

1. Clona il repository:

   ```bash
   git clone <URL-DEL-TUO-REPOSITORY>
   ```

2. Entra nella cartella del progetto:

   ```bash
   cd <NOME-DEL-REPOSITORY>
   ```

3. Apri il file HTML principale nel browser.

Se il file è denominato `index.html`, puoi semplicemente aprirlo con Chrome, Firefox, Edge o un altro browser moderno.

### Metodo 2 — Pubblicazione con GitHub Pages

Puoi pubblicare il gioco gratuitamente tramite GitHub Pages.

1. Carica il file HTML nel repository.
2. Se necessario, rinominalo `index.html`.
3. Apri le impostazioni del repository su GitHub.
4. Cerca la sezione **Pages**.
5. Seleziona il branch da pubblicare e la cartella principale del repository.
6. Salva la configurazione e attendi la pubblicazione.

Una volta disponibile, potrai condividere il link del gioco e permettere ad altre persone di provarlo direttamente dal browser.

## 🛠️ Tecnologie utilizzate

Il progetto è sviluppato utilizzando tecnologie web native.

| Tecnologia | Utilizzo |
|---|---|
| HTML5 | Struttura dell'interfaccia e dei menu |
| CSS3 | Grafica, layout responsive, animazioni e schermate |
| JavaScript | Logica di gioco, livelli, collisioni, progressione e interazioni |
| HTML Canvas | Rendering degli scenari, del personaggio e degli oggetti |
| Web Audio API | Generazione degli effetti sonori e della musica |
| LocalStorage API | Salvataggio locale dei progressi |

### ⚙️ Struttura del progetto

Nella versione attuale, il progetto è contenuto in un singolo file HTML.

```text
tuscany-dash/
└── index.html    # HTML, CSS, JavaScript e logica di gioco
```

Questa struttura rende il gioco semplice da distribuire e modificare, senza dover configurare un ambiente di sviluppo complesso.
